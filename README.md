# 班级管家 · Class Manager

面向班主任的轻量班级管理系统原型。无需后端、无需构建，打开网页即可使用，数据保存在浏览器本地。

## 功能

- **班级总览** — 人数、最近考试均分、整体出勤率、违规次数、成绩趋势、出勤构成、违规类型分布、积分榜与重点关注名单。
- **学生管理** — 学生增删改查、搜索与小组筛选，自动汇总每人的积分、出勤率与违规次数。
- **成绩分析** — 多场考试管理、逐人录入分数、排名与进退步对比、分数段分布。
- **自动奖惩** — 按“较上次考试进步 / 下滑”的阈值自动生成奖惩积分；阈值与分值可在设置中调整，也可一键重算。
- **出勤管理** — 按日期登记出勤 / 迟到 / 请假 / 缺勤，支持一键全部出勤；迟到与缺勤自动扣分，可重算。
- **违规记录** — 违规类型与扣分标准可自定义，记录后自动扣分，支持按学生统计与排行。
- **奖惩积分** — 积分排行榜、积分构成、完整流水，支持手动加减分。
- **系统设置** — 班级信息、成绩奖惩规则、出勤扣分规则、违规类型、JSON 数据导入 / 导出、恢复示例数据。

## 运行方式

纯静态页面，任选其一：

1. 直接双击 `index.html`（部分浏览器对本地文件限制较少，推荐方式 2）。
2. 在项目目录启动静态服务器：

   ```bash
   python3 -m http.server 8000
   ```

   然后访问 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库的 `main` 分支。
2. 打开仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
3. 稍等片刻，访问 `https://<用户名>.github.io/Class/`。

## 数据说明

- 所有数据保存在浏览器 `localStorage`（键名 `class-manager/v2`），不会上传服务器。
- 换浏览器、清缓存或换设备会导致数据不同步，请在「系统设置 → 数据管理」中定期**导出 JSON**备份，必要时再导入。
- 页面内置一份 20 名学生的示例数据，可在设置中恢复或通过“恢复示例数据”重置。

## 积分规则（默认）

| 场景 | 规则 |
| --- | --- |
| 成绩进步 | 较上次考试提升 ≥ 5 分，+3 积分 |
| 成绩下滑 | 较上次考试下降 ≥ 5 分，−2 积分 |
| 迟到 | −2 积分 |
| 缺勤 | −5 积分 |
| 违规 | 按违规类型扣分（如未交作业 −3、使用手机 −5） |
| 手动加减分 | 课堂表现、劳动、活动等，自定义分值 |

> 所有规则均可在「系统设置」中修改。

## 目录结构

```
├── index.html              页面骨架与导航
├── assets/
│   └── styles.css          全局视觉样式与响应式布局
└── js/
    ├── store.js            数据模型、示例数据、localStorage、积分计算
    ├── charts.js           纯 SVG 折线 / 柱状 / 条形 / 环形图
    ├── ui.js               弹窗、提示、格式化与通用组件
    ├── app.js              Hash 路由与应用入口
    └── views/
        ├── dashboard.js    班级总览
        ├── students.js     学生管理
        ├── grades.js       成绩分析
        ├── attendance.js   出勤管理
        ├── violations.js   违规记录
        ├── rewards.js      奖惩积分
        └── settings.js     系统设置
```
